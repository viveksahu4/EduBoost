ABSTRACT

In modern pedagogical institutions, student performance evaluation traditionally depends on summative end-of-term examinations. Such evaluation mechanisms fail to account for multi-dimensional performance indicators such as attendance, negative score trajectories, and individualized cognitive learning preferences. As a consequence, academically struggling students ('slow learners') are either diagnosed too late or subjected to generic, one-size-fits-all remedial coaching that yields negligible improvement.

EduBoost is a production-grade, data-driven academic analytics and remedial teaching platform engineered on Microsoft ASP.NET Core (.NET 10), Entity Framework Core, and SQL Server. The core architecture incorporates an empirical Multi-Factor Weighted Risk Detection Engine that evaluates student assessment averages (60% weight), institutional attendance ratios (25% weight), and declining performance trends (15% weight) to flag students in real time.

Once flagged, students undergo an embedded VARK (Visual, Auditory, Reading/Writing, Kinesthetic) Diagnostic Assessment. Based on their identified cognitive modality, the system correlates suitable interventions from an Innovative Teaching Methods Library (Peer Tutoring, Gamified Quizzes, Mind Maps, Storytelling, and Flipped Classrooms) and generates a tailored 4-week remedial plan using a dual-mode AI engine with deterministic offline fallback. Continuous progress logging, accreditation CSV exports, Transact-SQL view/stored procedure mappings in EF Core, OpenAPI/Swagger documentation, and an automated xUnit test suite ensure technical and pedagogical excellence.

CHAPTER 1: INTRODUCTION

1.1 Background and Motivation

Educational diversity is an inherent characteristic of any academic classroom. While high-performing students quickly grasp conceptual abstractions, slow learners require differentiated pedagogical scaffolding to assimilate curriculum benchmarks. When learning gaps remain unaddressed, students experience severe academic anxiety, leading to course failure, backlogs, and elevated dropout statistics.

Accreditation bodies worldwide (including NAAC, NBA, and ABET) mandate that higher education institutions establish a transparent, auditable mechanism to: (1) systematically identify slow learners, (2) formulate personalized remedial interventions, (3) employ innovative pedagogical methodologies, and (4) measure post-remedial outcome improvements. Traditionally, teachers maintain student marks and attendance across disjointed spreadsheets, resulting in delayed identification and lack of auditability. EduBoost solves this systemic problem through an integrated, automated software pipeline.

CHAPTER 3: SYSTEM ARCHITECTURE & MATHEMATICAL FORMULATION

3.1 Mathematical Risk Engine Formulation

EduBoost computes an empirical multi-factor risk index R ∈ [0, 100] using the formula:

Risk Calculation Formula
R = Clamp( (100 - AvgMarks) × 0.60 + (100 - Attendance) × 0.25 + Max(0, -Trend) × 0.15,  0,  100 )

Where:
• AvgMarks: Mean percentage across all completed assessments (0 ≤ AvgMarks ≤ 100).
• Attendance: Institutional attendance percentage recorded for the student (0 ≤ Attendance ≤ 100).
• Trend: Delta between latest test percentage and earliest test percentage.
• Max(0, -Trend): Declining trend penalty (e.g. 70% down to 45% adds +3.75 risk points).

CLASSIFICATION CRITERIA:
A student is flagged as a Slow Learner (IsSlowLearner = true) if and only if:
    AvgMarks < 40%   ∨   RiskScore ≥ 45.0

CHAPTER 5: CONCLUSION & FUTURE SCOPE

5.1 Conclusion

The EduBoost platform successfully automates the early identification of slow learners and provides an individualized remedial coaching framework. By replacing delayed single-exam cutoffs with a multi-factor quantitative risk engine, the system ensures timely intervention. Integrating VARK cognitive profiling, innovative teaching libraries, dual-mode AI remedial plans, and longitudinal progress tracking provides an end-to-end framework for student capacity building.

From an engineering perspective, the project demonstrates proficiency in modern Microsoft .NET 10 development, including Dependency Injection, Entity Framework Core with native Transact-SQL views and stored procedures, ASP.NET Core Identity with role-based access control, secured RESTful APIs with DTOs, Swagger documentation, and automated xUnit test suites.
